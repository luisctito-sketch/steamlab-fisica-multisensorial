# STEAMLab · Física multisensorial universitaria

Repositorio sugerido: `steamlab-fisica-multisensorial`

## Contenido
- `index.html` → aula interactiva multisensorial.
- `laboratorio_fisica_futurista.png` → fondo del laboratorio.

## Cómo publicarlo en GitHub Pages
1. Crea un repositorio nuevo llamado `steamlab-fisica-multisensorial`.
2. Sube `index.html`, `README.md` y `laboratorio_fisica_futurista.png`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y carpeta `/root`.
6. Guarda los cambios.
7. Tu enlace quedará parecido a:
   `https://TU-USUARIO.github.io/steamlab-fisica-multisensorial/`

## Características
- Interacciones visuales con puntos brillantes.
- Sonido breve y seguro con Web Audio API.
- Movimiento y vibración opcional para el componente táctil.
- Analogías guiadas para olfato y gusto como recurso didáctico.
